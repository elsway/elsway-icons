No install, no framework

Use the CDN directlyno build step

The icons live in a public GitHub repo, so jsDelivr mirrors them on its global edge network for free — no npm, no Vercel dependency, works in a plain <img> tag.

CDN URL pattern

https://cdn.jsdelivr.net/gh/elsway/elsway-icons@v1/public/raw/elsway/{brand}/{weight}/{name}.svg

Example: .../cars24/fill/4k.svg — same brand/weight/name values as above.

<img
  src="https://cdn.jsdelivr.net/gh/elsway/elsway-icons@v1/public/raw/elsway/cars24/fill/4k.svg"
  width="24" height="24" alt="4k"
/>

@v1 is pinned and cache-friendly — it won't change under you. Swap it for @main only if you deliberately want to always track the newest icons (slower cache, can change without notice).

One stylesheet, no JS

Or link one stylesheet, then use a classno JS

Pick one brand+weight CSS file — outline or solid — then every icon is just a class name.

<link rel="stylesheet"
  href="https://cdn.jsdelivr.net/gh/elsway/elsway-icons@v2/public/cdn/cars24-fill.css" />

<i class="ai ai-4k"></i>
<i class="ai ai-heart" style="color:#1a1a1a; font-size:32px"></i>

Color comes from color, size from font-size — ordinary CSS, no data attributes. Each file covers all 1,402 icons for that one brand+weight (~2–3.8 MB uncompressed, ~400–700 KB gzipped over the CDN). Under the hood each class is a CSS mask-image, not a real webfont — same feel, no font-building step. Requires @v2 — these files postdate @v1.

Download the whole library4 formats

The round button at the bottom-right of the site opens Download library. Pick a brand, then a format. The archive is built in your browser — nothing is uploaded, and nothing is generated on a server.

Every download carries both weights. There is no weight picker — regular and fill always ship together, and the file name says which is which:

svg/heart-regular.svg
svg/heart-fill.svg
svg/broken-heart-regular.svg
svg/broken-heart-fill.svg

The suffix is deliberate. It sorts both weights of an icon next to each other, and it matches the glyph names inside the font — so heart-fill means the same thing whether you consume the SVGs or the font.

Using it in code

One URL powers every framework

There is no npm package. Every icon is a plain SVG at a stable URL, so integration is the same everywhere: build the URL, render it. Nothing to install, nothing to keep in sync when icons change.

The only thing to remember

https://cdn.jsdelivr.net/gh/elsway/elsway-icons@v2/public/raw/elsway/{brand}/{weight}/{name}.svg

brand default · cars24 · carinfo · teambhp · vehicleinfo  —  weight regular · fill

React

A ten-line componentno dependency

Copy this once and you have every icon, brand and weight.

// Icon.jsx
const BASE = "https://cdn.jsdelivr.net/gh/elsway/elsway-icons@v2/public/raw/elsway";

export function Icon({ name, brand = "default", weight = "regular", size = 24, ...rest }) {
  return (
    <img
      src={`${BASE}/${brand}/${weight}/${name}.svg`}
      width={size}
      height={size}
      alt=""
      {...rest}
    />
  );
}

Then anywhere:

<Icon name="heart" brand="cars24" weight="fill" size={32} />

An <img> cannot be recoloured with CSS. If you need the icon to follow currentColor, mask it instead:

export function Icon({ name, brand = "default", weight = "regular", size = 24 }) {
  const url = `${BASE}/${brand}/${weight}/${name}.svg`;
  return (
    <span
      aria-hidden
      style={{
        display: "inline-block",
        width: size, height: size,
        backgroundColor: "currentColor",
        WebkitMask: `url(${url}) center / contain no-repeat`,
        mask: `url(${url}) center / contain no-repeat`,
      }}
    />
  );
}

React Native

Render through react-native-svg

React Native has no SVG renderer of its own, so this is the one platform that needs a real dependency.

npm install react-native-svg
import { SvgUri } from "react-native-svg";

const BASE = "https://cdn.jsdelivr.net/gh/elsway/elsway-icons@v2/public/raw/elsway";

export function Icon({ name, brand = "default", weight = "regular", size = 24, color }) {
  return (
    <SvgUri
      width={size}
      height={size}
      color={color}
      uri={`${BASE}/${brand}/${weight}/${name}.svg`}
    />
  );
}

Shipping icons inside the app instead of fetching them? Drop the .svg files into your project and swap SvgUri for react-native-svg-transformer, which lets you import Heart from "./heart.svg".

Vue 3

A single-file component

<!-- Icon.vue -->
<script setup>
const props = defineProps({
  name:   { type: String, required: true },
  brand:  { type: String, default: "default" },
  weight: { type: String, default: "regular" },
  size:   { type: Number, default: 24 },
});

const BASE = "https://cdn.jsdelivr.net/gh/elsway/elsway-icons@v2/public/raw/elsway";
const src = computed(() => `${BASE}/${props.brand}/${props.weight}/${props.name}.svg`);
</script>

<template>
  <img :src="src" :width="size" :height="size" alt="" />
</template>

Used as:

<Icon name="heart" brand="cars24" weight="fill" :size="32" />

Icon font

Install one font, type any iconboth weights

Every brand ships as a single font holding all 2,804 glyphs — both weights in the one file, so a project installs one font rather than two. Download it from Download library → TTF.

What is in the TTF download
FileWhat it is
autonaut-{brand}.ttfThe font — install it anywhere a font goes
autonaut-{brand}.woffThe same font, web-optimised
autonaut-{brand}.css@font-face plus a class per glyph
codepoints.jsonEvery glyph name mapped to its codepoint

On the web, link the CSS and use a class. The weight is part of the class name, not a separate stylesheet:

<link rel="stylesheet" href="autonaut-cars24.css" />

<i class="ai-heart-regular"></i>
<i class="ai-heart-fill" style="color:#1a1a1a; font-size:32px"></i>

Colour and size come from color and font-size, exactly like a letter.

Anywhere that is not a browser — Figma, Sketch, native apps, a design tool — install the .ttf and type the codepoint. Codepoints live in the Private Use Area starting at U+E900; codepoints.json lists all of them, and they mean the same icon in every brand:

heart-regular  U+EBCD
heart-fill     U+F147

Two things to know. The font CSS claims every class starting ai-, so do not load it alongside the mask-based cars24-fill.css stylesheet above — pick one approach per page. And a handful of icons are drawn with strokes rather than filled shapes, which a font cannot represent; those few glyphs are incomplete in the font only. The SVGs are always exact.

Swift · SwiftUI

Add the SVGs to your asset catalog

SwiftUI cannot decode SVG at runtime, so remote loading needs a third-party decoder. The reliable route is to bundle the icons you use.

Bundling an icon
StepWhat to do
1Download the .svg from the site or the CDN URL
2Drag it into Assets.xcassets — Xcode keeps it as a vector
3Set the asset's Render As to Template Image so it takes your tint
 
Image("heart")
    .renderable()
    .resizable()
    .renderingMode(.template)
    .frame(width: 32, height: 32)
    .foregroundStyle(.primary)

To load straight from the CDN instead, add an SVG decoder such as SDWebImageSVGCoder or SVGKit — AsyncImage alone will not render these files.
