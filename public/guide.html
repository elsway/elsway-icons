Browsing the library

Grab an icon from the site

No account needed — this covers the public read side of the site only.

  1. 1

    Open autonaut-icons.vercel.app.

  2. 2

    Pick a brand from the sidebar dropdown — Default, Cars24, CarInfo, TeamBHP, VehicleInfo. Same 1,402 icons, five corner treatments.

  3. 3

    Pick a weight (Regular outline or Fill solid) and drag the size slider at the top.

  4. 4

    Search by name, or browse categories in the left rail — counts update live.

  5. 5

    Click any icon to open its detail panel. Copy the raw SVG, or grab a ready snippet from the React / Web / Vue / Flutter / Elm / Swift tabs.

Or fetch an SVG directly, no site visit needed

https://autonaut-icons.vercel.app/raw/elsway/{brand}/{weight}/{name}.svg

Example: .../cars24/fill/4k.svg — brand is one of the five above, weight is regular or fill.

No install, no framework

Use the CDN directlyno build step

The icons live in a public GitHub repo, so jsDelivr mirrors them on its global edge network for free — no npm, no Vercel dependency, works in a plain <img> tag.

CDN URL pattern

https://cdn.jsdelivr.net/gh/elsway/elsway-icons@v1/public/raw/elsway/{brand}/{weight}/{name}.svg

Example: .../cars24/fill/4k.svg — same brand/weight/name values as above.

<img
  src="https://cdn.jsdelivr.net/gh/elsway/elsway-icons@v1/public/raw/elsway/cars24/fill/4k.svg"
  width="24" height="24" alt="4k"
/>

@v1 is pinned and cache-friendly — it won't change under you. Swap it for @main only if you deliberately want to always track the newest icons (slower cache, can change without notice).

Or link one stylesheet, then use a classno JS

Pick one brand+weight CSS file — same idea as choosing fa-solid vs fa-regular — then every icon is just a class name.

<link rel="stylesheet"
  href="https://cdn.jsdelivr.net/gh/elsway/elsway-icons@v2/public/cdn/cars24-fill.css" />

<i class="ai ai-4k"></i>
<i class="ai ai-heart" style="color:#e8612b; font-size:32px"></i>

Color comes from color, size from font-size — ordinary CSS, no data attributes. Each file covers all 1,402 icons for that one brand+weight (~2–3.8 MB uncompressed, ~400–700 KB gzipped over the CDN). Under the hood each class is a CSS mask-image, not a real webfont — same feel, no font-building step. Requires @v2 — these files postdate @v1.

Using it in code

Install the React packagenpm

One component covers every icon, brand, and weight — no per-icon imports.

npm install @autonaut-icons/react

Then:

import { Icon } from "@autonaut-icons/react";

function Toolbar() {
  return (
    <Icon name="4k" />
    <Icon
      name="heart"
      brand="cars24"
      weight="fill"
      size={32}
      color="#e8612b"
    />
  );
}
