Autonaut Icons — vehicleinfo / regular
========================================

1402 icons. Generated from the SVG source; do not hand-edit.

Files
  autonaut-vehicleinfo-regular.ttf       the icon font
  autonaut-vehicleinfo-regular.woff      same font, web-optimised
  autonaut-vehicleinfo-regular.css       helper classes
  codepoints.json       every icon name and its codepoint

Web
  1. Copy the font files and the CSS into your project.
  2. <link rel="stylesheet" href="autonaut-vehicleinfo-regular.css">
  3. <i class="ai-heart"></i>

Anywhere else (Figma, Sketch, native apps)
  Install autonaut-vehicleinfo-regular.ttf and type the icon's codepoint.
  Codepoints start at U+E900 and are listed in codepoints.json.

Colour and size follow the surrounding text, exactly like a letter:
  .my-icon { font-size: 32px; color: #1a1a1a; }
